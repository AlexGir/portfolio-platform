Rôles et droits

Les trois rôles de base livrés avec la plateforme. L’affichage de chaque écran découle de ces capacités : un utilisateur ne voit jamais les écrans de gestion qu’il ne peut pas utiliser.

Rôles personnalisés
L’admin compose un nouveau rôle à partir de ces capacités quand les trois rôles de base ne suffisent pas.
Visibilité manuelle
Un admin peut ouvrir un écran à une personne précise sans changer son rôle, pour couvrir les cas particuliers.
Inscriptions
Validation automatique possible, désactivée pour les applications qui exigent plus de sécurité.
